# Clinical/technical domain glossary — Vietnamese ↔ English

| Tiếng Việt | Technical term | Distinction |
|---|---|---|
| Bệnh nhân | Patient | Durable identity; not simply phone number |
| Phòng khám / cơ sở khám chữa bệnh | Clinic / Licensed Facility | May be different from a business group or branch |
| Lượt khám | Encounter | Clinical episode; not an appointment |
| Lịch hẹn | Appointment | Intent to visit; not performed procedure |
| Ghế nha | Chair / Resource | Must be transactionally reserved |
| Sơ đồ răng | Odontogram | Projection of dated clinical finding history |
| Mặt răng | Tooth surface | Location of a clinical finding; expert-defined labels |
| Ghi chú bệnh án | Clinical Note | Draft vs authenticated document clearly separated |
| Hồ sơ đã ký | Authenticated Clinical Document | Requires verified lawful signature/confirmation, not hash alone |
| Bản bổ sung | Addendum | New linked artifact; original signed record preserved |
| Kế hoạch điều trị | Treatment Plan | Versioned clinician plan; not action automatically performed |
| Giai đoạn điều trị | Treatment Phase | Clinician-defined milestone/dependency |
| Công việc điều phối | Treatment Task | Administrative task status not equal to procedure completion |
| Labo | Dental Laboratory | External/clinic case-handling partner with narrow access |
| Công nợ | Receivables / Patient Balance | Ledger-driven amount independent of clinical status |
| Đặt cọc | Deposit | Payment event not a completed procedure |
| Bệnh án giấy cũ | Legacy paper record | Preserved original provenance, never backdated digital signature |
| Biểu mẫu | Clinical Form Template | Official version, reviewed field mapping and effective period |
| Truy vết | Provenance / Audit | Who/what/when and linked exact source |
| Ký/xác nhận | Signature / Authentication | Legal mechanism must be independently reviewed |
| Liên thông | Interoperability | FHIR/DICOM adapters and approved actual partner endpoints |
| Người bảo hộ/đại diện | Related Person / Guardian | Verified authority and limited rights |
